# Guarded JSON-RPC requests

This source candidate builds on the exact compatibility commit `9a91c22b9baa60f7237637a032d4c29159b8e16b` and pins the transport candidate `b6ef58590241babdb4fe52e916a02c9e2b749e3d` from [Starscream PR5](https://github.com/soramitsu/fearless-starscream/pull/5). Both remain candidates awaiting independent review and protected release qualification.

`JSONRPCOptions(writeAuthorization:)` carries an application-owned authorizer to the final Starscream transport handoff. It cannot enable reconnection replay. Ordinary request options retain their existing defaults. `JSONRPCOperation` accepts immutable request options, publishes request IDs safely across cancellation, and cancels guarded requests when they time out. Timeout remains an unknown outcome until the application reconciles chain state.

The engine keeps a per-attempt generation alongside the transport cancellation handle. Cancelling an unsent request prevents its queued or dequeued write. Accepted bytes without an RPC result produce `submissionOutcomeUnknown`; neither reconnect nor subscription rescheduling replays guarded mutations. A callback from an old attempt cannot settle a reused UInt16 request ID. A premature server response cannot complete bytes that were never handed off. Guarded request payloads are omitted from pending-request debug output.

Replacing a URL creates a new engine and requires a fresh handshake, cancels guarded work on the old connection, retains ordinary pending reads, and ignores old socket callbacks. RPC response callbacks run outside the RPC mutex. Unsubscription decodes outside that mutex and safely reacquires it only for response bookkeeping, avoiding nested request-lock deadlocks and preserving a replaced subscription.

The application authorizer must hold fresh, intent-bound authority through a synchronous handoff, after its own durable I/O and clock sampling. It must not reenter this SDK, prepare/sign data, wait for writer-dependent work, or retain the nonescaping closure. It contains no secret-key material. The app must still check exact wallet/chain/asset/route/transaction bytes before key access and signing, and reconcile hashes, fees and finality afterward.

`python3 scripts/test-authorized-rpc.py` copies byte-identical production networking, scheduling, model constants and RobinHood base-operation source into an isolated narrow package. It resolves the shipping Starscream revision and the wallet's pinned Reachability revision, records source hashes, and requires 21 distinct passing XCTest cases with no skips. Tests exercise the real SDK and writer queue with controlled transport/clock fixtures; Starscream separately supplies real local TCP coverage. This does not replace a full iOS app build, migration tests, physical devices or distribution acceptance. No resolved production dependency is patched.
